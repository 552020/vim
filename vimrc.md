# The vimrc file

Normally we have 3 vimrc in our system
- /etc/vim/vimrc 

This is the system-wide vimrc file, which applies to all users on the system

- ~/.vimrc 

This is the user-specific vimrc file. The user specifi vimrc file takes precedence over the system-wide vimrc file

- /usr/share/vim/vimrc

This is a system wide vimrc file, not meant not be edited. It contains the default configuration settings for Vim and is used when no other vimrc file is found.
